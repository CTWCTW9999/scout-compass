# 斥候罗盘

在 iPhone Safari 打开固定 HTTPS 网页，输入任意文字或直接点“查询附近”，每次查询重新获取当前位置，列出直线 1 公里内的门店候选及地图定位、步行导航。文字仅触发查询，不会当作关键词、更改筛选条件或发送给外部服务。无需安装 App，也无需飞书。

公开入口：https://ctwctw9999.github.io/scout-compass/

私人启用入口另行交付，链接片段带 AES-256-GCM 配置解锁钥匙，不提交到源码仓库。本人收藏此入口即可自动启用已配置的高德 JavaScript 接口。

## 实际完成的能力

- 前台 GPS 定位，`maximumAge: 0`，拒绝超过 30 秒的位置；拒绝误差超过 300 米的位置；显示定位时间和误差。
- WGS84 与高德 GCJ02 坐标转换，按计算的直线距离复核 1000 米边界。高德 JavaScript 检索逐页展示已返回的候选，后台继续补全；未完成或中断时明确标注列表不完整。
- 默认 OpenStreetMap / Overpass 检索，不需 API Key。两家公共服务顺序尝试，各 18 秒超时；网络错误与成功零结果分开显示。
- 可使用高德 **JavaScript Key＋安全密钥**，经官方 JS SDK 的 PlaceSearch 检索。也可切换高德 Web 服务周边检索，需 **Web 服务 Key**。Key 仅在页面内存，不保存、不提交到代码仓库。请求由浏览器直接发到高德。需保证 Key 授权、配额和访问限制允许该方式；公开多人服务应改成带限流的服务端代理。
- 优先 5 类、扩展 23 类。高德每品类分页最多 8 页、每页 25 条；达到接口上限或部分品类失败会显示说明；POI 去重、距离排序。开放地图只覆盖有对应标签的子集。
- 六个核验项执行原五条条件，其中“金额储值”和“闲置余额”分别核查。核验来源完整、90 天内有效且达到门槛才显示“已核验符合”。任一有证据的项不合格则排除，缺证据保持候选。
- 核验记录仅保存在当前浏览器本地。设置同样本地保存；输入文字、位置、Key 不存储。私密浏览、清除浏览器数据或换设备可能失去记录。
- 演示入口全部为虚构商家，定位、导航、电话禁用；退出演示后不沿用模拟位置。

## 尚未解决的数据条件

**当前没有已核验门店数据库，也没有任何真实的逐店闲置率数据。** `stores.json` 初始为空。地图数据不能确认未消费 Wi-Fi、弱绑定共享、主推充值档及正常完整最低价格，更无法证明闲置率。不能把候选列表说成全部符合。

上线前于 2026-10-21 测试了公共 Overpass 服务：主实例返回 406，另外两个实例超时；因此无法确认该网络下免密钥检索可用。网页保留实际查询和错误提示，但国内可靠检索仍建议配置高德 Key。用户提供的 Key 经 Web 服务验证返回 USERKEY_PLAT_NOMATCH（10009），应使用 JavaScript 接口；不能混用。JavaScript 实际检索验收另见交付记录。

默认的主推实付充值 ≥500 元、≥90 天未核销的付费余额占比 ≥50% 是本项目给出的**可调整工作口径**，不是用户指定标准或行业事实。正常完整一次消费必须 **<50 元**，50 元整不合格。

共享指原会员明确授权他人使用付费余额，非未经许可使用账户。个体工商户身份不等同于非连锁；加盟和直营都应排除。

## 使用高德数据

1. 打开 https://console.amap.com/dev/key/app 登录已开通的高德开发者账号。
2. 在“应用管理 → 我的应用”找到或创建自己的应用，添加服务平台为 **Web 服务** 的 Key。注册、认证、服务协议及费用由账号所有者操作。
3. 网页“数据设置 → 高德地图”填入 Key，再点“应用设置”。重新查询；刷新后需要重填 Key。
4. 出现错误码时检查 Key 类型、访问白名单、配额与服务授权。不要使用别人的公开 Key。

## 核验库格式

`stores.json` 的 `stores` 可添加 `{ "store": {...}, "record": {...} }`。store 格式与 `core.js` 中规范化门店相同，`point` 为 WGS84，`mapPoint` 为 GCJ02；record 与 `app.js` 核验表单生成的格式相同。只发布店家公开规则及允许公开的匿名证据，绝不包含个人会员手机号、账户或私有余额。

## 开发与部署

无构建。高德 JavaScript 模式按需从官方 webapi.amap.com 在线加载 SDK；不转存或打包 SDK。Node 22：`npm test`。本地用静态 HTTP 服务；localhost 可定位，手机应使用 HTTPS。

GitHub Pages 从 `main` 分支根目录发布。源码可复用，位置、输入文字、明文 Key 和安全密钥不进入 Git。私人凭证加密保存在 private-config.json，解锁钥匙在私人入口的 URL 片段中；片段不会通过 HTTP 请求或 Referer 发给 GitHub Pages。拿到完整私人入口的人可解锁配置，因此不要公开分享。配置解密后会在浏览器内由高德 SDK 使用；这并不隐藏使用者浏览器中的凭证。多人服务应部署服务端代理，并按高德要求保护安全密钥。

数据来源：OpenStreetMap（ODbL，https://www.openstreetmap.org/copyright）、高德周边搜索（https://lbs.amap.com/api/webservice/guide/api/search）、高德 URI（https://lbs.amap.com/api/uri-api/guide/point）。
